# Web-Scraper-Tool-Python-
## ✨ Features - Extract HTML tables into pandas DataFrames - Parse and save article or paragraph text from web pages - Download linked documents (PDFs, etc.) from matching URLs - Customizable scraping logic per site layout
## 🔧 Tech Stack
- Python 3.x
- BeautifulSoup (`bs4`)
- `requests`
- `re`, `os`, `pandas`, `time`

## 📂 Example Use Cases
- Research paper collection from academic portals (e.g., arXiv)
- Bulk download of public datasets
- Automated scraping of blog/article archives
- Structured content extraction from static sites
